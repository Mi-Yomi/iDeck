## Native architecture and pins

This is the Madeira-derived native iOS Wine/FEX stack, not a Linux VM. Swift/UIKit/
SwiftUI and C/Objective-C/Rust host Wine's unix side on iOS; FEX translates x86/x64,
Wine supplies Windows APIs/WoW64/ARM64EC, DXMT maps D3D9/10/11 to Metal and
madeira-d3d12 supplies D3D12 via Apple's Metal Shader Converter. The host has native
GameController/input and StikJIT/pairing paths. A direct comparison/import must
preserve native runtime ownership, prefixes, account stores and per-game config.

## Licence boundaries

LICENSE/COPYING contain GPL3. Madeira code uses GPL3-or-later plus the adopted
Converter Exception. BCD Material files use GPL3-only plus its exception and
GPL section7 terms. Preserve all original headers/notices/history, modification
notes/dates, contributors and the exact UI/legal credit:

    Includes work from BCD by thebcd69 (https://github.com/thebcd69/bcd-games)

Use our own branding before distributing a modified app and do not imply BCD,
Madeira, Valve or Apple endorsement. Private hosting does not remove recipients'
licence rights when a binary is conveyed. Prepare exact corresponding source,
recursive pins, patches, build/signing instructions and all required notices for
that binary. This is an engineering inventory, not a legal compliance guarantee.

The top-level THIRD-PARTY-NOTICES.md still has an outdated GPL-converted Wine row;
the actual pinned Wine branch's LICENSE-MADEIRA.md says LGPL2.1-or-later. Keep the
upstream document intact for import and record the discrepancy rather than
silently treating the stale table as the grant. Upstream's static LGPL relinking
section explicitly says it does not currently ship a relinking package. Source
availability alone does not resolve all binary/relinking obligations.

The old iDeck transport has no root LICENSE grant for the proposed custom Swift
files; the pinned Husk source slice contains GPL version2 text. This does not
establish whether each source is GPL2-only,2-or-later, original or derived. Do not
copy its files into this GPL3 app until per-file rights/compatibility and relevant
linking permissions are established. Transfer desired behavior using BCD's
existing APIs instead. No old Linux/ext4/QEMU payload, cache or recovery code is
part of this import. No GPL2/GPL3 compatibility conclusion is invented.

Some documents referenced by notices/scripts, including docs/LICENSING.md and
